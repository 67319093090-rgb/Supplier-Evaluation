คู่มือการใช้งาน

คู่มือการใช้งานระบบ Supplier Evaluation

1. ภาพรวมระบบ

ระบบใช้สำหรับจัดเก็บข้อมูลผู้ผลิต ประเมินผู้ผลิตตาม 5 ด้าน และสรุปคะแนนอัตโนมัติ

ลำดับการใช้งาน: เพิ่มผู้ผลิต → ประเมินคะแนน → บันทึกผล → ตรวจสอบ Dashboard/รายงาน

2. เพิ่มผู้ผลิต

  1. เลือกเมนู “ผู้ผลิต”
  2. กด “เพิ่มผู้ผลิต”
  3. กรอกชื่อ ผู้ติดต่อ ใบรับรอง และวันที่เริ่ม
  4. กดบันทึก

เมื่อบันทึกแล้วผู้ผลิตจะปรากฏในรายการและสามารถเลือกไปประเมินได้

3. ประเมินคะแนน

  1. เลือกเมนู “ประเมินคะแนน”
  2. เลือกผู้ผลิต
  3. ให้คะแนนแต่ละด้าน 0–20
  4. ตรวจสอบคะแนนรวม
  5. กดบันทึกผลการประเมิน

ระบบรองรับ 5 ด้าน: Q คุณภาพ, P ราคา, R การตอบสนอง, D การส่งมอบ, S การบริการ

4. เกณฑ์คะแนน

คะแนนระดับผล
85–100ดีเยี่ยมผ่าน
70–84ผ่านผ่าน
60–69ควรปรับปรุงควรติดตาม
0–59ไม่ผ่านไม่ผ่าน

5. Dashboard

Dashboard คำนวณจำนวนผู้ผลิต คะแนนเฉลี่ย จำนวนผู้ที่ควรปรับปรุง และจำนวนผู้ที่ไม่ผ่าน พร้อมกราฟแบ่งตามระดับคะแนนและ Top 10 ผู้ผลิต

6. รายงาน

ใช้ตัวกรองระดับผลประเมินและชื่อผู้ผลิตได้ สามารถส่งออกข้อมูลเป็น CSV ซึ่งเปิดด้วย Excel ได้ และใช้ปุ่ม PDF/พิมพ์เพื่อบันทึกเป็น PDF จากหน้าพิมพ์ของเบราว์เซอร์

7. แก้ไขและลบ

ในหน้าผู้ผลิต กดปุ่มแก้ไขเพื่อเปลี่ยนข้อมูล และกดถังขยะเพื่อลบ หากลบผู้ผลิต ผลการประเมินของผู้ผลิตนั้นจะถูกลบด้วย

8. สิทธิ์ผู้ใช้

Admin จัดการข้อมูลทั้งหมด, Evaluator ประเมินและดูรายงาน, User ดูข้อมูลและรายงาน

ระบบตัวอย่างนี้ยังไม่ใช้ฐานข้อมูลออนไลน์ หากต้องการให้หลายคนใช้งานและเห็นข้อมูลเดียวกัน ต้องเชื่อม Backend/Database เพิ่ม
