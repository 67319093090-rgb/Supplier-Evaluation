คู่มือการใช้งาน

คู่มือฉบับละเอียดสำหรับระบบ Supplier Evaluation ตั้งแต่เข้าสู่ระบบจนถึงการจัดทำรายงาน

สารบัญคู่มือ

1. เริ่มต้นใช้งานระบบ

Supplier Evaluation เป็นระบบสำหรับจัดเก็บข้อมูลผู้ผลิต ประเมินผลตามเกณฑ์ 5 ด้าน คำนวณคะแนนเต็ม 100 คะแนน และสรุปผลเป็นระดับเพื่อช่วยติดตามคุณภาพของผู้ผลิต

ขั้นที่ 1เข้าสู่ระบบด้วย Username และ Password
ขั้นที่ 2เพิ่มหรือเลือกข้อมูลผู้ผลิต
ขั้นที่ 3ประเมินคะแนนและบันทึกผล
ลำดับแนะนำ: เข้าสู่ระบบ → Dashboard → ผู้ผลิต → เพิ่มผู้ผลิต → ประเมินคะแนน → ตรวจสอบผล → รายงาน

เมนูด้านซ้ายใช้สำหรับเปลี่ยนหน้าการทำงาน โดยระบบจะแสดงผลในหน้าเดียวและปรับให้เหมาะกับคอมพิวเตอร์และโทรศัพท์มือถือ

2. การเข้าสู่ระบบ

เมื่อเปิดเว็บไซต์ ระบบจะแสดงหน้าล็อกอินก่อนเข้าสู่ระบบ เพื่อให้ผู้ใช้งานยืนยันตัวตนก่อนใช้งานเมนูต่าง ๆ

  1. กรอกชื่อผู้ใช้ในช่อง ชื่อผู้ใช้
  2. กรอกรหัสผ่านในช่อง รหัสผ่าน
  3. หากต้องการตรวจสอบรหัสผ่าน ให้กดปุ่ม แสดง
  4. กด เข้าสู่ระบบ
บัญชีสาธิต: Username admin / Password admin123
หมายเหตุ: ระบบนี้เป็นต้นแบบสำหรับการนำเสนอและเก็บข้อมูลในเบราว์เซอร์ จึงไม่ควรใช้รหัสผ่านนี้กับระบบงานจริงที่มีข้อมูลสำคัญ

เมื่อเข้าสู่ระบบสำเร็จ จะเห็นชื่อผู้ใช้งานและสิทธิ์ที่มุมด้านบนของเมนูด้านซ้าย และสามารถกด ออกจากระบบ เมื่อใช้งานเสร็จ

3. ภาพรวม Dashboard

Dashboard เป็นหน้าสรุปข้อมูลสำคัญของระบบในภาพรวม ช่วยให้ผู้ใช้เห็นสถานะการประเมินได้อย่างรวดเร็ว

  • จำนวนผู้ผลิต: จำนวนผู้ผลิตทั้งหมดที่บันทึกในระบบ
  • คะแนนเฉลี่ย: ค่าเฉลี่ยของผู้ผลิตที่มีผลการประเมินแล้ว
  • ควรปรับปรุง: จำนวนผู้ผลิตที่ได้ 60–69 คะแนน
  • ไม่ผ่าน: จำนวนผู้ผลิตที่ได้ต่ำกว่า 60 คะแนน

ด้านล่างมีกราฟแสดงจำนวนผู้ผลิตตามระดับผลประเมิน และตาราง Top 10 ผู้ผลิต เรียงจากคะแนนสูงไปต่ำ

หากเพิ่มหรือแก้ไขผลประเมิน ระบบจะคำนวณ Dashboard ใหม่อัตโนมัติ

4. เพิ่มข้อมูลผู้ผลิต

ข้อมูลผู้ผลิตเป็นข้อมูลพื้นฐานที่ต้องมี ก่อนทำการประเมินคะแนน

  1. ไปที่เมนู ผู้ผลิต
  2. กด เพิ่มผู้ผลิต
  3. กรอกชื่อผู้ผลิต
  4. กรอกชื่อผู้ติดต่อ
  5. กรอกข้อมูลใบรับรอง เช่น ISO 9001, ISO 14001, GMP หรือ HACCP
  6. กรอกวันที่เริ่มต้น
  7. ยืนยันการบันทึกข้อมูล

เมื่อเพิ่มสำเร็จ รายชื่อจะปรากฏในตารางผู้ผลิต และสามารถกด ประเมิน เพื่อไปยังหน้าประเมินคะแนนได้ทันที

คำแนะนำ: ควรกรอกชื่อผู้ผลิตให้ชัดเจนและไม่ซ้ำกัน เพื่อให้ง่ายต่อการค้นหาและจัดทำรายงาน

5. แก้ไขและลบข้อมูล

การแก้ไข

ในหน้าผู้ผลิต ให้ค้นหารายการที่ต้องการ แล้วกดปุ่ม ✎ ระบบจะให้แก้ไขชื่อผู้ผลิต ผู้ติดต่อ และใบรับรอง จากนั้นข้อมูลจะถูกบันทึกใหม่

การลบ

กดปุ่ม ♲ ในรายการที่ต้องการลบ แล้วกดยืนยัน ระบบจะลบข้อมูลผู้ผลิตและผลการประเมินของรายการนั้นออกจากเบราว์เซอร์

ระวัง: การลบข้อมูลไม่สามารถเรียกคืนได้จากหน้าระบบ ดังนั้นควรตรวจสอบชื่อผู้ผลิตก่อนยืนยันการลบ

6. การประเมินคะแนน

ระบบประเมินผู้ผลิตใน 5 ด้าน ด้านละ 0–20 คะแนน รวมเต็ม 100 คะแนน

รหัสหัวข้อคะแนนเต็มสิ่งที่ใช้พิจารณา
Qคุณภาพ20คุณภาพสินค้า ความสม่ำเสมอ และข้อบกพร่อง
Pราคา20ความเหมาะสมของราคาและความคุ้มค่า
Rการตอบสนอง20ความรวดเร็วในการติดต่อและแก้ไขปัญหา
Dการส่งมอบ20ตรงเวลา ครบจำนวน และถูกต้องตามคำสั่งซื้อ
Sการบริการ20การประสานงานและการให้บริการหลังการขาย
  1. เลือกผู้ผลิต
  2. กรอกคะแนนแต่ละด้าน 0–20
  3. ตรวจสอบคะแนนรวมที่ระบบคำนวณให้
  4. ตรวจสอบระดับผลประเมิน
  5. กด บันทึกผลการประเมิน

7. เกณฑ์การตัดสินผล

คะแนนรวมเต็ม 100 คะแนน ระบบแบ่งระดับผลประเมินดังนี้

คะแนนรวมระดับความหมาย
85–100ดีเยี่ยมผลการประเมินอยู่ในระดับสูงมาก
70–84ผ่านผ่านเกณฑ์ที่กำหนด
60–69ควรปรับปรุงควรติดตามและปรับปรุงบางด้าน
0–59ไม่ผ่านไม่ผ่านเกณฑ์ ควรพิจารณาแนวทางแก้ไข
ตัวอย่าง: ได้ Q18 + P16 + R17 + D18 + S17 = 86 คะแนน → ดีเยี่ยม

8. การอ่าน Dashboard

หลังบันทึกผล ระบบจะนำคะแนนไปสรุปบน Dashboard โดยอัตโนมัติ

  • ดูจำนวนผู้ผลิตทั้งหมดจากการ์ด จำนวนผู้ผลิต
  • ดูคะแนนเฉลี่ยของรายการที่ประเมินแล้วจาก คะแนนเฉลี่ย
  • ตรวจจำนวนรายการที่อยู่ในช่วง 60–69 จาก ควรปรับปรุง
  • ตรวจจำนวนรายการต่ำกว่า 60 จาก ไม่ผ่าน
  • ใช้กราฟเพื่อเปรียบเทียบจำนวนผู้ผลิตในแต่ละระดับ
  • ดู Top 10 เพื่อค้นหาผู้ผลิตที่มีคะแนนสูง

ข้อมูลใน Dashboard จะเปลี่ยนทันทีเมื่อมีการบันทึกผลใหม่ แก้ไขข้อมูล หรือล้างข้อมูล

9. รายงานและการส่งออก

หน้า รายงาน ใช้สำหรับตรวจสอบผลการประเมินในรูปแบบตาราง และค้นหาข้อมูลเฉพาะรายการ

  1. เลือกผลประเมิน เช่น ดีเยี่ยม ผ่าน ควรปรับปรุง หรือไม่ผ่าน
  2. พิมพ์ชื่อผู้ผลิตในช่องค้นหา
  3. ตรวจสอบคะแนนและระดับผล
  4. กด Excel/CSV เพื่อดาวน์โหลดข้อมูลสำหรับเปิดใน Excel
  5. กด PDF / พิมพ์ เพื่อเปิดหน้าพิมพ์และเลือกบันทึกเป็น PDF
CSV เหมาะสำหรับนำข้อมูลไปวิเคราะห์ต่อ ส่วน PDF เหมาะสำหรับจัดเก็บหรือส่งรายงาน

10. สิทธิ์ผู้ใช้

บทบาทหน้าที่
Adminจัดการข้อมูลผู้ผลิต ประเมินคะแนน ดู Dashboard และรายงาน

หน้า สิทธิ์ผู้ใช้ ใช้แสดงแนวคิดเรื่อง Role ของระบบ ส่วนบัญชีที่ใช้ในเวอร์ชันสาธิตคือ admin / admin123

ระบบต้นแบบนี้ยังไม่มีฐานข้อมูลออนไลน์หรือการเข้ารหัสรหัสผ่านแบบระบบ Production หากนำไปใช้งานจริงควรเชื่อมฐานข้อมูลและระบบยืนยันตัวตนฝั่งเซิร์ฟเวอร์

11. การแก้ปัญหาเบื้องต้น

  • กดเข้าระบบไม่ได้: ตรวจสอบ Username และ Password ให้ตรงกับบัญชีสาธิต
  • ไม่มีรายชื่อผู้ผลิต: ไปที่เมนูผู้ผลิตและเพิ่มข้อมูลก่อน
  • บันทึกคะแนนแล้วไม่เห็น Dashboard: กลับไปที่ Dashboard หรือรีเฟรชหน้าเว็บ
  • กราฟยังเป็น 0: ตรวจสอบว่ามีการบันทึกผลการประเมินแล้ว ไม่ใช่เพียงกรอกคะแนนไว้
  • ข้อมูลหาย: เวอร์ชันนี้เก็บข้อมูลใน Local Storage ของเบราว์เซอร์ หากล้างข้อมูลเว็บไซต์หรือเปลี่ยนอุปกรณ์ ข้อมูลอาจไม่ปรากฏ
สำหรับการนำเสนอ: ควรใช้เบราว์เซอร์เดิมและอุปกรณ์เดิมที่บันทึกข้อมูลไว้ หรือกด “เพิ่มข้อมูลตัวอย่าง” เพื่อเตรียมข้อมูลสาธิตใหม่

12. สรุปขั้นตอนการทำงาน

1 · Loginยืนยันตัวตนก่อนเข้าสู่ระบบ
2 · ผู้ผลิตเพิ่มและตรวจสอบข้อมูลผู้ผลิต
3 · ประเมินให้คะแนน 5 ด้าน รวม 100 คะแนน
4 · สรุปผลระบบแบ่งระดับตามเกณฑ์ 85/70/60
5 · Dashboardดูกราฟและ Top 10
6 · รายงานค้นหาและส่งออกผลการประเมิน
สรุปสั้นสำหรับการนำเสนอ: ระบบช่วยจัดเก็บข้อมูลผู้ผลิต → ประเมิน 5 ด้าน → คำนวณคะแนนอัตโนมัติ → แบ่งระดับผล → แสดง Dashboard และสร้างรายงาน
